# 🎓 GBU GrievanceHub

A modern **Grievance Management & Ticket Tracking System** developed for the **GBU IT Cell Recruitment Challenge 2026**. The application provides an intuitive interface for students to submit grievances, track their status, and for administrators to manage grievance tickets efficiently.

---

**Vercel:** https://gbu-grievance-hub-two.vercel.app/

---

## 📂 GitHub Repository

**Repository:** https://github.com/7218544818/GBU-GrievanceHub

# ✨ Features

### 👨‍🎓 Student Portal
- Submit grievances online
- Upload supporting details
- Automatic Ticket ID generation
- Track grievance status
- Responsive interface

### 👨‍💼 Admin Dashboard
- Dashboard overview
- Ticket management
- Status updates
- Category-wise statistics
- Interactive charts
- Recent tickets table

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/7218544818/GBU-GrievanceHub.git
```

Navigate to the project

```bash
cd GBU-GrievanceHub
```

Install dependencies

```bash
pnpm install
```

Start the development server

```bash
pnpm dev
```

Build for production

```bash
pnpm build
```
